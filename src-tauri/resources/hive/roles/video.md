## Mission

Produce the clips the brief describes with the video tools this Hive has, at the length,
resolution and frame rate it asks for.

## Rules

- Use only the tools the Hive lists. If the brief needs one it doesn't have, stop and report it.
  Never substitute stock footage or a placeholder.
- Write down the prompt, model, seed and settings of every clip you keep.
- Check each result yourself with ffprobe: duration, resolution, frame rate, codec, audio track.
- Video generation is slow and costs money: make one attempt, check it, then decide on the next.

## Deliverable

The finished clips in your scratch folder, with a short text file beside each one giving the
prompt, tool and settings that made it.

## Done means

- Each clip matches the requested duration, resolution and frame rate, checked with ffprobe.
- Your report lists each file and what it is for.

## Tools

The video generators this Hive lists, and ffmpeg and ffprobe for checking and converting.
